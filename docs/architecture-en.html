Where data lives · privacy

Code on GitHub (shareable)
Pullers, analysis workflows, dashboard UI, commands. Anyone can clone and run /onboard <their-ID> to rebuild the whole thing.
Data stays local (never uploaded)
Your posts, analyses, voice, drafts, images, keys — all gitignored. Your content never leaves your machine.
Keys in .env.local
TikHub for pulling, Mistral Voxtral for voice interviews. Neither enters git. Your own login cookie works too, for free.
Everything rebuilds from an ID
Data is disposable and regenerable. The scripts are the product. A different ID is a different person's dashboard.
