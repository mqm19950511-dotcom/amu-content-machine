数据怎么存 · 隐私

代码上 GitHub（可分享）
抓取脚本、分析流程、看板 UI、命令。任何人 clone 下来，跑 /onboard <自己的ID> 就能重建整套。
数据留本地（不上传）
你的笔记、分析、语音、草稿、图片、keys —— 全部 gitignored。你的内容永远不离开你的电脑。
Keys 在 .env.local
TikHub 抓数据、Mistral Voxtral 做语音访谈。都不进 git。也可以用你自己的登录 cookie，免费。
一切可从 ID 重建
数据是一次性的、可再生的。脚本才是产品。换个 ID 就是另一个人的看板。
