# Substack Sources

Scanned by `/scan` via RSS. Every Substack exposes `<url>/feed` — no auth needed, full text.
This is the most reliable source list in the system; invest here.

Mark `⚡` on publications where you regularly think *"right, but they're missing something."*
Those generate the best response opportunities.

**Keep those marks in `sources/substacks.local.md`** — gitignored, unlike this file.

**Status:** starter list, unverified. Delete aggressively — 15 publications you actually read
beat 50 you don't. Set `Read:` to `always` / `sometimes` / `never` after a few weeks and let
`/oracle` weight accordingly.
